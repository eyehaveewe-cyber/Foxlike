# Credits

Direction and project ownership: Jonathan Sanders / eyehaveewe-cyber.

Foxlike is an original arcade game implemented for the owner's one-shot build request. Asterion locations, squadron identities and the Arrow/Dragonfly/RIME design language draw from the owner's Project Barrel Roll, with explicit permission. Foxlike's game-specific models, animation, scenery, code and sound effects were created procedurally. The Anchorage carrier directly adapts Project Barrel Roll's Dragonfly hull. Mission music includes three excerpts from the owner's original MBean1 composition *The Bone Lantern Ballroom*, newly rendered through its original Web Audio engine; the initial Foxlike boss music remains in use. Editable source scores and rendering code are included. See [source references](docs/SOURCES.md) and [carrier/music provenance](docs/ASSET_IMPORTS.md) for exact commits and distinctions.
